# Wazuh log sources

Collect and label events from:

- Keycloak authentication and administration
- pfSense firewall decisions
- Reverse proxy and protected application access
- Server and endpoint agents
- OPA authorization decisions where available
- Suricata alerts and flow metadata

Validation records should include a test ID, timestamp, source, destination/resource, expected result, observed result, and related event identifiers. Monitoring health should also detect missing agents, disabled sensors, and interrupted log feeds.
